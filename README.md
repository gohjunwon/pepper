# Pepper — 미국주식 호재 레이더

오늘의 호재, 1달 앞 일정, 실적 미리보기, 시장 일정을 한국 시각으로 보는 사이트입니다.

## 언제 갱신되나요
**Claude 연결 없이** GitHub Actions(`.github/workflows/update.yml`)가 혼자 갱신합니다. 실행 신호는 Cloudflare 알람(`tools/cloudflare-worker.js`)이 보냅니다.

| 무엇 | 언제 |
|---|---|
| 오늘의 호재·시간외 호재 | 30분마다 |
| **장 시작 1시간 전 필수 갱신** | 뉴욕 8:30(서머타임 자동, 미국 휴장일 제외). 5·10·15분 뒤 실제 실행을 확인해 안 됐으면 다시 보냄(최대 3번) |
| 개장 직전 집중 갱신 | 개장 50·40·30·20·10·5분 전, 개장, 개장 5분 후 |
| 1달 앞 일정·시장 일정·실적 미리보기·캘린더 | 하루 두 번(한국 06:40, 20:40) |
| 예비(알람이 멈췄을 때) | 3시간마다, 뉴욕 8:22 무렵(GitHub 예약), 매일 한국 22:23 전체 |

- 내용이 바뀌지 않으면 `/my/` 암호 파일을 다시 만들지 않고, 갱신 시각만 바뀐 경우 2시간 안에는 커밋하지 않아 저장소가 커지지 않습니다.
- 공개 사이트에는 관심종목이라서만 들어간 종목은 싣지 않습니다(관심종목은 `/my/`에서만 보임).
- 자료: Yahoo Finance(주가·뉴스·애널리스트 전망), Nasdaq(실적·경제 달력), Google 뉴스, 무료 구글 번역

## 비밀값 (Settings → Secrets and variables → Actions → New repository secret)
| 이름 | 필수 | 내용 |
|---|---|---|
| `MY_PASS` | ○ | 나만 보는 /my/ 사이트 비밀번호 |
| `WATCHLIST` | ○ | 관심종목, 예: `CPNG,TSLA` |
| `NTFY_TOPIC` | 선택 | 장외 호재 진동 알림용 주제 이름 |
| `GCAL_SA_JSON`, `GCAL_ID` | 선택 | 구글 캘린더에 바로 넣기 |

## 설정 방법
### 1) 장외 호재 진동 알림 (ntfy, 무료)
1. 휴대폰에 **ntfy** 앱을 설치합니다(플레이스토어·앱스토어).
2. 앱에서 **+ → 주제 구독**, 남이 짐작하기 어려운 이름을 정합니다. 예: `pepper-7k3x9q2m` (이 이름을 아는 사람은 누구나 알림을 볼 수 있으니 길고 무작위로).
3. GitHub 비밀값 `NTFY_TOPIC`에 같은 이름을 넣습니다.
4. 미국장 마감 뒤~다음 장 시작 전에 새로 잡힌 '오늘의 호재'만, 종목당 한 번씩 진동으로 옵니다. 장중에는 오지 않습니다. 소리 없이 진동만 원하면 앱의 알림 설정에서 소리를 끄세요.

### 2) 구글 캘린더에 바로 넣기 (선택 — 안 하면 구독 주소 방식)
1. <https://console.cloud.google.com> → 새 프로젝트 → **API 및 서비스 → 라이브러리**에서 *Google Calendar API* 사용 설정.
2. **사용자 인증 정보 → 서비스 계정 만들기** → 만든 계정 → **키 → 새 키(JSON)** 다운로드.
3. 구글 캘린더에서 **새 캘린더 만들기**(예: Pepper) → 설정 → **특정 사용자와 공유**에 서비스 계정 이메일(…@…iam.gserviceaccount.com)을 *일정 변경* 권한으로 추가.
4. 같은 설정 화면의 **캘린더 ID**를 비밀값 `GCAL_ID`에, 다운로드한 JSON 파일 내용 전체를 `GCAL_SA_JSON`에 넣습니다.
5. 하루 두 번 전체 갱신 때 1달 앞 일정이 바로 들어갑니다(같은 일정은 중복되지 않고 고쳐짐, 알림 없음).
- 설정하지 않으면: 구글 캘린더 '다른 캘린더 → URL로 추가'에 `https://gohjunwon.github.io/pepper/data/calendar.ics` (구글이 12~24시간마다 읽어 늦게 반영될 수 있음).

### 3) Cloudflare 알람 고치기 (이 저장소의 `tools/cloudflare-worker.js`가 바뀌면)
1. Cloudflare 대시보드 → **Workers & Pages** → 알람 Worker → **코드 편집**.
2. 기존 코드를 모두 지우고 `tools/cloudflare-worker.js` 내용을 붙여넣은 뒤 **배포**.
3. **설정 → 트리거(Cron Triggers)** 를 `*/5 * * * *` 하나로 바꿉니다(5분마다).
4. 비밀값 `GH_TOKEN`(GitHub 토큰, 6개 저장소 Actions 읽기·쓰기)이 있는지 확인.
5. Worker 주소를 브라우저로 열면 저장소별 연결 상태·마지막 실행 시각·다음 1시간 예정이 보입니다.

투자 권유가 아니며, 모든 정보는 공개된 기사·공시를 바탕으로 자동 수집·번역합니다.
